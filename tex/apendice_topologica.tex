\chapter{Resultados Completos da Validação Cruzada da Via Topológica}
\label{apendice:topologica}

Os desempenhos obtidos pelos codificadores da via topológica durante o procedimento de validação cruzada estratificada em cinco partições estão reunidos neste apêndice. Para cada conjunto de dados e para cada modelo avaliado, são detalhados os hiperparâmetros ótimos selecionados ($\eta, p, h, B$), a média de épocas executadas até a ativação da parada antecipada, a acurácia média e a pontuação de F1 macro acompanhada do desvio padrão.
